# Project Agent Guidelines: ThreadNote

## 1. Tech Stack & Environment
- **Framework:** React Native with Expo (TypeScript)
- **Local Storage:** Expo File System & SQLite
- **Version Control:** Git (Conventional Commits standard)

## 2. Directory Structure
- `/spec` - System concept and specifications.
- `/src` - Application source code.
- `/tests` - Unit and integration tests.
- `/docs` - Project documentation.
- `/logs` - Development logs and agent profiles.

## 3. Development Rules
- Follow TypeScript strict types.
- Write modular, reusable components.
- Use Conventional Commits for all Git commit messages (e.g., `feat:`, `fix:`, `docs:`).
